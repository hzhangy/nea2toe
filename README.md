## Code Files

This repository contains the numerical experiments and meta‑audits for Papers VII of the N.E.A. framework.

### Paper VII: Anisotropy Stretches Space, Isotropy Compresses Space

- **`nea_anisotropy_evolution.py`**  
  Simulates the topological attractor of the continuous zig‑zag: how anisotropy expands living dimensions while isotropy compresses dead dimensions. Generates the phase‑transition plots used in Paper VII.

- **`nea_fractal_34_scaling.py`**  
  Demonstrates the 3/4 power‑law scaling (Kleiber’s law analogue) that emerges from fractal folding under bandwidth constraints. Produces the scaling figures for biological and economic cross‑layer audits.
